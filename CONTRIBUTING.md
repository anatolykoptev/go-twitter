# Contributing

Bug reports, fixes and improvements are welcome. For a larger change, open an issue first so we can agree on the approach.

## Development

You need the Go version named in [go.mod](go.mod).

```bash
make preflight
```

This runs gofmt, `go vet`, the build and the tests. The same command gates every pull request.

## Pull requests

- Keep each pull request to one change.
- Add a test when the bug or behaviour would otherwise fail silently.
- Update the guide in [docs](docs) when you change behaviour it describes.
- Use [Conventional Commits](https://www.conventionalcommits.org/) in the pull request title, for example `fix(parsers): keep pinned tweets`. Releases and the changelog are generated from these titles.

## Generated files

`internal/operations/queryids_gen.go` and `internal/operations/features_gen.go` are generated by `cmd/gql-sync`. Regenerate them rather than editing by hand. See [Maintenance](docs/maintenance.md).

## Tests and sensitive data

Tests must run offline: no requests to x.com and no real accounts. Fixtures must not contain cookies, tokens, proxy credentials or private messages. Replace real values before you commit a recorded response.

## Security issues

Report vulnerabilities as described in [SECURITY.md](SECURITY.md), not in a public issue.
